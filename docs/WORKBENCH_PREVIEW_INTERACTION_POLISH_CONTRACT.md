## Product scope

1. **Chat.** Use accepted `Message`, `MessageAvatar`, `Avatar` and `AvatarFallback`; compact single-letter avatars start/left for incoming and end/right for outgoing, preserving message text and grouped-message compatibility. Keep the old contact header absent. Structure the full-height card as a normal vertical flex/grid layout with an expanding message region and composer at the bottom, including when paired with Recent activity. Preserve `Type your message...`; keep an enabled, filled semantic-primary send icon button inside the field with accessible name and visible focus. Submit may remain a no-op. No chat state, persistence or network.
2. **Weather.** Remove only the five forecast low-temperature values and their orphaned accessibility text/row space. Keep weekday, icon, high and order. Remove fixed weight overrides on large current temperature and Lisbon so both inherit the live Body role weight, while preserving Body family, sizes and hierarchy. Do not replace semibold with another fixed weight.
3. **Design system.** In this preview only, paired semantic swatches display `Background` and `Foreground`; token keys, sidebar editor labels and alias semantics do not change. Display resolved current-token HEX equivalents only as specimen text, with no theme storage/serialization change. Use wider-than-tall rectangular swatches with narrow containment. Remove Sidebar alias helper lines, use the heading `SIDEBAR`, and remove the Type scale summary metadata while retaining all nine specimens, labels and live Body behavior. Confirm Sidebar OFF/ON and light/dark values.
4. **Reset toast.** Replace only reset's inline notice with floating, transient feedback and an `Undo` action. Adapt the official shadcn Base UI Toast recipe using the already-installed `@base-ui/react` Toast primitive; no Sonner installation or custom notification framework. Retain the existing inline notice channel for other save/delete/error messages. Undo must invoke the existing history operation and restore the immediately pre-reset editable state; later unrelated edits or theme switches must not leave a stale toast Undo targeting the wrong history step. Dismissal changes no history. No focus theft, layout shift, uncontrolled stack or second undo model. Keep the public registry at 23 by integrating toast locally in Workbench.
5. **App shells.** Moderately increase the contained height of Classic workspace, Inset project and Compact utility, preserving order, landscape proportion and responsive containment. Each starts expanded and independently collapses/restores an icon rail via the existing shadcn Sidebar provider/state/trigger pattern. Use one preview-local provider per shell; no shared collapse persistence. Scope embedded positioning and keyboard shortcuts so one shell cannot control another. Preview iframe interactions must never change the actual Workbench Sidebar and Workbench controls must never change a preview shell. Preserve the public Sidebar API, existing themed tokens and accessible icon labels; its accepted implementation has no Tooltip resource, so do not assume tooltip support. No second sidebar framework.
6. **Bitcoin.** Keep Chat and Recent activity paired, move the full-width Bitcoin card immediately after their row and before Data table, and leave all other gallery order intact. Remove the visible source/date caption, retaining non-UI provenance. Replace the badge with a card-local accessible 1Y/3Y/5Y segmented selection, default 1Y. Preserve the accepted 1Y frozen observations; add bounded, hard-coded representative approximately 3-year and 5-year series with fixed date cadence and non-UI provenance/illustrative status. Headline price and percent change derive from selected endpoints. Preserve line+dots, hidden axes, chart tokens, fixed chart footprint, and light/dark behavior. No API, SDK, runtime fetch, live pricing, credential, trading control or worker network.
